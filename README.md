## 🌟 Overview

**Nādabrahma** (Sanskrit: *नादब्रह्म* — *"The Divine Reality as Sound and Vibration"*) is an all-in-one, local-first audio workstation that unifies:
1. **Universal Music Composition:** Indian Classical (Ragas, Talas, 22 Shrutis, Moveable *Sa*) fused with global and Western genres.
2. **Beyond Music:** Cinematic Background Scores (BGM), Commercial / Documentary Voice-Overs, Audio-Drama, A Cappella Aalaps, Foley & Sound Design.
3. **Multi-Model AI Orchestration:** Native adapters for **YuE 2**, **MiniMax Music 3**, **ACE Studio / DiffSinger**, **Stable Audio 3**, and **Vāgdhenu (Sanskrit Chant TTS)**.
4. **All-in-One Powerhouse Heritage:** Complete synthesis of features from **theDAW** (composition, scoring, lyrics, 3D spatial audio), **Resonant** (clip launcher, MCP agentic server, Seed-VC), and **StemForge** (BS-Roformer stems, UVR cleanup, polyphonic MIDI extraction, RVC voice conversion).
5. **Director’s Mode (Intuitive for Non-Composers):** Scene creation driven by the **9 Rasas (Navarasa)**, automatic raga/scale suggestions, and a 15–30s custom voice drop box with reinterpretation.
6. **Ultra-HD Extended Spectrum (10 Hz – 48,000 Hz):** Native **96 kHz / 32-bit float** engine with automatic Per-Track **Hypersonic Air (20k–48k Hz)** and **Somatic Infrasound (10–20 Hz)**.
7. **Engineered for Mac M1 Max (32GB Unified Memory):** Optimized for **Apple Silicon MLX, audio.cpp, Metal Performance Shaders (MPS), and CoreAudio** for zero memory leaks, instant inference, and buttery-smooth performance.
